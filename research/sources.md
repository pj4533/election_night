# Sources by category

Snapshot taken 2026-11-03 (election night) by the research agents. Raw JSON is in `raw/`. Re-verify endpoints before relying on them.


## Paid / commercial APIs

Short version: there is no cheap, self-serve, real-time paid results API that an individual can buy tonight. The two real commercial feeds, AP and Decision Desk HQ, are both sales-gated with no published prices. The only live APIs I could probe and use right now are the free Kalshi and Polymarket market APIs. They give odds, not vote counts.

What I verified with curl tonight:
- Kalshi: https://api.elections.kalshi.com/trade-api/v2/markets?event_ticker=CONTROLH-2026 returned JSON with HTTP 200 and no key. The Democratic House contract showed last_price 0.97.
- Polymarket: https://gamma-api.polymarket.com/events returned JSON with HTTP 200 and no key. The slug which-party-will-win-the-house-in-2026 resolves.
- AP: the developer portal loads, but api.ap.org/v2/elections returned 403 without a key.
- DDHQ: the docs site loads. The API needs OAuth credentials that I could not obtain.

What I could not confirm:
- No AP or DDHQ prices. Both appear to be contact-sales only.
- Whether DDHQ has any hobbyist tier. I found none.
- Update latency for AP and DDHQ was not stated in anything I could read.
- Reuters/Edison, Clarity/Civix, Ballotpedia, RapidAPI listings, and other cheap resellers were not searched or probed, so my slice is incomplete there. Another agent should cover county-level sources such as Clarity/SOE feeds and the Dutchess County BOE.

Dashboard implication: prediction-market odds plus any free official or state/county feeds from other slices are the realistic route tonight. Paid AP or DDHQ access would need a sales conversation and is unlikely to be granted to an individual in time.

## Free & open data

Bottom line for the free tier: nothing free and documented gives live US results. The only free live-ish options are (1) civicAPI.org (claims free, up-to-the-minute 2026 results; endpoints unverified, my guesses 502/404, so inspect its Embed/Help pages), and (2) scraping state/county sites. For Dutchess County, the BOE posts results via Enhanced Voting at app.enhancedvoting.com/results/public/dutchess-county-ny/GE2026 (200 OK, Angular SPA). It has no documented API; the backing JSON must be found with browser dev tools, and the county historically posts slowly (PDFs after the night). The NY State BOE site is behind a Cloudflare challenge (403 to curl). Post-election and context sources are all free and working: OpenElections NY (precinct CSVs, pushed 2026-10-23), MIT Election Lab/Harvard Dataverse (API up), FEC (verified returning NY-18 2026 candidates with DEMO_KEY, but it is finance, not results), Wikipedia (live-ish human-edited). Google Civic: Representatives API was shut down April 2025; Elections/Divisions remain (key required, probed: service up, 403 without key) but contain no vote counts. elex is archived since 2022 and needs a paid AP key (api.ap.org returns 401, alive). Clarity/clarify works only for Clarity jurisdictions, and Dutchess is not one. Verdict: a dashboard is feasible, using a paid or semi-official live feed for statewide/national races plus the discovered Enhanced Voting JSON for Dutchess, with OpenElections/MIT for baselines. Caveats: I did not verify civicAPI's real endpoint, nor Enhanced Voting's JSON, nor certain 2025/2026 OpenElections coverage."

## Media undocumented feeds

The best find is the NYT undocumented JSON feed, which is live for the 2026 midterms. The pattern is https://static01.nyt.com/elections-assets/pages/data/2026-11-03/results-{senate|house|governor|new-york|new-york-governor}.json. I curled it at about 7:18pm ET and got HTTP 200, no auth, and CORS open. Headers show cache-control max-age=5 with a last-modified stamp 22s old, so the files refresh every few seconds. The data is AP-sourced and includes NYT model estimates. It goes down to county level: the NY governor file has 63 units, and Dutchess County rows exist in the governor race (156 precincts), NY-17 (21 precincts) and NY-18 (135 precincts). Vote counts were all 0 for NY when I checked, because NY polls had not closed (9pm ET), so real values are unverified. There is no presidential race this year, so results-president and results-ballot-measures return 404. ToS risk is real: it is undocumented, NYT's terms prohibit scraping and commercial reuse, and the files could be changed or blocked at any time. It is fine for a personal dashboard, but poll gently (10-30s, ETag) and credit NYT/AP. For CNN, Politico, WaPo, NBC and Fox I could not confirm a 2026 feed. My path guesses returned 404 or bot blocks (403/000), and web search only turned up 2016 and 2020 patterns. The next step there is to capture network requests in a real browser. The official AP Elections API (api.ap.org/v3/elections) responds 403 and needs a paid key, with no published pricing found. I did not examine Dutchess BOE results beyond confirming that elections.dutchessny.gov loads (200). A dashboard looks feasible: poll the NYT state-scoped files from a small server and render NY governor and House results by county."}

## Dutchess County BOE

Dutchess County BOE hosts election-night results on the Enhanced Voting platform, not on Clarity/Scytl, Civera, KnowInk or ElectionStats. ## ENR vendor platforms & state feeds

Bottom line from the vendor/state-feed slice. No vendor offers a documented, supported real-time API. What exists is a mix of undocumented JSON/XML behind official sites and bulk file drops.

Confirmed live by curl:
- North Carolina's S3 bucket (dl.ncsbe.gov/ENRS/2026_11_03/) responds and is the cleanest official statewide bulk feed. It is open, unauthenticated, precinct-level, with a results_pct zip. The results zip still showed a 2026-10-05 timestamp at my probe, about 7:20pm ET before NC polls closed, so I have not seen it update live.
- Georgia's CDN export pattern works (the 2024 export is 200, 32 MB, precinct-level JSON, max-age=60). I could not find the 2026 election ID; it needs the SPA's network calls.
- Clarity's root responds, but I could not find a live instance to confirm the JSON or XML paths. Clarity URLs need a numeric election ID that is unpredictable and has no central index. Everything I say about /json/en/summary.json, reports/detailxml.zip and current_ver.txt comes from third-party pages (cgorski.github.io, Firecrawl), not from my own probing.

Dutchess County: the BOE site (elections.dutchessny.gov) is a WordPress site with PDF/HTML results and a few old CSV/XLS files. It is NOT on Clarity (404). I found no API, and the board says results post slowly through the night, with absentees later. Plan on scraping its unofficial-results HTML page once the 2026 general page appears (I did not see it yet), or ask the BOE for CSV. I did not identify its vendor.

Blocked to curl (403 or bot challenge, so inconclusive, NOT proof of no API): NY State ENR (Cloudflare), PA (Imperva/Incapsula), TX, AZ, MO, IA. OH and MI did not connect. A headless browser (Playwright) would likely get through and let you read the XHR calls.

Not covered or not verified: KnowInk, Hart, ElectionStats, VR Systems, Tenex, Arcadia and Enhanced Voting were not researched with evidence. California has a documented JSON API (PDF found, not called). Washington has per-date CSV/XML export pages, but I could not find the 2026 one (404 on the guesses). Florida has pages reachable but no file endpoints confirmed.

Practical recommendation from this slice: a dashboard built on NC's S3 files, Georgia's CDN JSON, CA's JSON API, and Playwright-assisted discovery for the big blocked states is feasible. For anything truly real-time or national, an AP-type aggregator is probably the real option; that was outside my slice. County-level coverage for Dutchess will be slow and manual regardless of feed choice.
